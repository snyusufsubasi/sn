# assets/icons

Bu klasöre koyulması gerekenler:

- `app_icon.png` (1024x1024 PNG, transparent veya beyaz arka plan) — `flutter_launcher_icons` bunu kullanır.
- `app_icon_foreground.png` (Android adaptive icon foreground, opsiyonel).

Komut:
```bash
dart run flutter_launcher_icons
```

İkonlar `pubspec.yaml`'da `flutter_launcher_icons` bloğunda tanımlı.
